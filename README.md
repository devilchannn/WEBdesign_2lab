# OBJECTS — Personal Art Archive

Полностью готовая лабораторная №2: HTML/CSS/Vanilla JS + ES-модули, классы, 2 внешних API.

## Как запустить

**Важно:** из-за `<script type="module">` нельзя надёжно проверять двойным нажатием на index.html с адресом `file://`.

- В Dreamweaver настройте локальный сервер или откройте папку в VS Code с расширением Live Server.
- Альтернатива при установленном Python: перейдите терминалом в папку OBJECTS, выполните `python3 -m http.server 8000`, откройте `http://localhost:8000`.
- Можно загрузить папку на GitHub и включить GitHub Pages (ветка main, /root): там ES-модули работают.

## Что проверять

1. В COLLECTION NOTES добавьте запись, отметьте checkbox, удалите запись.
2. Нажмите «−» и «×» у любой карточки. Через ADD WIDGET восстановите удалённую.
3. Обновите страницу: виджеты, состояние сворачивания, заметки и избранные работы останутся.
4. В ART DISCOVERY нажмите DISCOVER ANOTHER; в MUSEUM ARCHIVE попробуйте поиск `portrait` или `flower`.
5. Нажмите SAVE + у произведения — работа окажется в SAVED OBJECTS.
6. Отключите интернет в DevTools: сетевые карточки покажут ошибку и TRY AGAIN, а заметки продолжат работать.

## Внешние сервисы

- Art Institute of Chicago API: https://api.artic.edu/docs/
- The Met Collection API, актуальный поиск v1.1: https://metmuseum.github.io/

Сетевые ответы могут зависеть от доступности API в вашей сети. Демо-данные намеренно не подменяют сетевые результаты.

## Оформление

Цвета и шрифты меняются в начале `style.css` через CSS custom properties `:root`.

## Примечание

Все карточки независимы; строки из API выводятся через textContent, а не через HTML-инъекцию. Изображения берутся непосредственно с сайтов музеев.
